# PaddyCare AI - Precision Paddy Leaf Disease Detection & Analytics Platform

**PaddyCare AI** is an agricultural technology application that detects and classifies rice leaf diseases using a Convolutional Neural Network (CNN) trained with MobileNetV2 transfer learning. The platform features a React + TypeScript frontend, a Python FastAPI machine learning backend, and a persistent SQLite database for prediction history and telemetry.

---

## 🌟 Key Features

1. **AI-Powered Disease Detection**:
   - Classifies **Bacterial Leaf Blight**, **Rice Blast**, **Brown Spot**, and **Rice Tungro**.
   - Achieves **98%+ Validation Accuracy** on held-out test datasets.
   - Computes ranked softmax probabilities and confidence metrics.

2. **Interactive Agricultural Dashboard**:
   - Telemetry analytics showing total analyses, accuracy, and class distribution charts.
   - Recent scan feeds and quick action upload triggers.

3. **Persistent Diagnostic History**:
   - Automatically records all prediction scans, original filenames, images, and confidence scores in SQLite.
   - Full search, disease filtering, sorting, pagination, and CSV export functionality.

4. **Comprehensive Disease Library & Crop Care Guide**:
   - Authoritative agricultural recommendations for symptoms, environmental triggers, preventive practices, and curative chemical/biological controls.

5. **Model Specifications & Performance**:
   - Detailed breakdown of CNN architecture, confusion matrix cross-tabulation, and edge-case limitations.

---

## 🏗️ Tech Stack

- **Frontend**: React 18, TypeScript, Vite, Tailwind CSS, Framer Motion, Recharts, TanStack Query, Lucide Icons, Canvas Confetti.
- **Backend**: Python 3.10+, FastAPI, TensorFlow / Keras 2.21, Pillow, NumPy, SQLAlchemy, Pytest.
- **Database**: SQLite 3 (`paddycare.db`).
- **ML Backbone**: MobileNetV2 (Transfer Learning + Fine-tuning) trained on 5,932 paddy leaf images.

## 🚀 Quickstart Guide

### 1. Environment Setup

```bash
# Clone or navigate to the project directory
cd e:/paddy

# Create and activate Python Virtual Environment (Optional but recommended)
python -m venv venv
# On Windows PowerShell:
.\venv\Scripts\Activate.ps1
```

### 2. Install Backend Dependencies

```bash
pip install -r backend/requirements.txt
```

### 3. Install Frontend Dependencies

```bash
cd frontend
npm install
cd ..
```

---

## 🏃 Running the Application

### Start Backend API Server

```bash
# From the root directory (e:/paddy)
uvicorn backend.app.main:app --reload --host 0.0.0.0 --port 8000
```
- API Documentation available at: `http://localhost:8000/docs`
- Health check endpoint: `http://localhost:8000/api/health`

### Start Frontend Dev Server

```bash
# In a second terminal inside e:/paddy/frontend
cd frontend
npm run dev
```
- Open `http://localhost:5173` in your browser.

---

## 🧠 Model Training & Evaluation

To re-train or fine-tune the CNN model on the dataset:

```bash
python backend/scripts/train.py
```
This trains MobileNetV2 on `Rice Leaf Disease Images/` and outputs:
- Saved Keras Model: `backend/models/paddy_cnn_model.keras`
- Class Mapping: `backend/models/class_indices.json`
- Performance Metrics & Confusion Matrix: `backend/models/model_metrics.json`

To evaluate the saved model:
```bash
python backend/scripts/evaluate.py
```

Or open `Paddy_CNN2.ipynb` in Jupyter / VS Code for interactive training & loss curve visualization.
